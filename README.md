# Pet Boutique

Landing page para pet shop com apresentação de serviços, marcas parceiras e localização.

**Demo:** https://rogerrochago02.github.io/Pet-Boutique/

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `style.css` — estilos e layout

## Como executar

```bash
git clone https://github.com/rogerrochago02/Pet-Boutique.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
